前770年 周の東遷、春秋時代へ。孔子（前551年生 #bc/05/5/1 ）はこの時代の末に現れる。 #bc/07/7/0

前403年 三家分晋、戦国時代の始まり。諸子百家が競い合う思想の黄金期でもある。 #bc/04/0/3 #歴史/思想史

前221年 秦が中国を統一 {ev qinx0221 #bc/02/2/1 }

前202年 劉邦が漢を建てる。武帝期（前141年〜前87年 #bc/01/4/1 ）には張騫の西域派遣でシルクロードが開かれた。 #bc/02/0/2

184年 黄巾の乱、後漢の崩壊はじまる。 #ad/01/8/4
220年 曹丕が漢を簒奪、三国時代へ。 #ad/02/2/0

589年 隋が南北朝を統一。大運河の建設（605年〜 #ad/06/0/5 ）は後世の経済地理を規定した。 #ad/05/8/9

618年 唐朝が建国 {ev tang0618 #ad/06/1/8 }

755年 安史の乱おこる。唐の最盛期の終わり——日本ではこの3年前に東大寺大仏が開眼している。 #ad/07/5/5 #歴史/世界のなかの中国

875年 黄巣の乱（〜884年）。唐は事実上ここで崩れる。 #ad/08/7/5
907年 唐滅亡、五代十国へ。 #ad/09/0/7

960年 北宋建国。士大夫の時代、火薬・羅針盤・活版印刷の実用化。 #ad/09/6/0 #歴史/科学技術
1127年 靖康の変、北宋滅亡。南宋は臨安（杭州）へ。 #ad/11/2/7

1206年 チンギス・カンの即位はモンゴル帝国の始まり——中国史でも世界史でもある。 {ev mong1206 #ad/12/0/6 #histolog/中国史 #histolog/ヨーロッパ史 }

1279年 崖山の戦い、南宋滅亡・元の統一。 #ad/12/7/9
1368年 朱元璋が明を建国。 #ad/13/6/8
1405年 鄭和の南海遠征はじまる（〜1433年）。 #ad/14/0/5 #歴史/世界のなかの中国

1644年 明朝の滅亡、清の入関 {ev ming1644 #ad/16/4/4 }

1840年 アヘン戦争。以後の百年は「屈辱の世紀」と呼ばれる。 {ev opiu1840 #ad/18/4/0 #histolog/中国史 #histolog/ヨーロッパ史 }
1851年 太平天国の乱（〜1864年）。 #ad/18/5/1
1894年 日清戦争、洋務運動の破綻が露呈。 #ad/18/9/4
1911年 辛亥革命、二千年の帝政が終わる。 {ev xinh1911 #ad/19/1/1 #histolog/中国史 }
1949年 中華人民共和国成立。 #ad/19/4/9
