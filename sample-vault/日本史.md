## 先史〜古代

前3世紀ごろ、水稲耕作と金属器が朝鮮半島経由で広まり、社会は弥生時代へ移行する。環濠集落や高床倉庫が現れ、余剰生産をめぐる戦いが始まった。 #bc/03 #歴史/考古学

239年 卑弥呼が魏に遣使し、「親魏倭王」の称号と銅鏡百枚を受ける。邪馬台国の所在地（畿内説 vs 九州説）は今も決着していない。 #ad/02/3/9 #歴史/名詞と概念/邪馬台国

538年 仏教公伝（一説に552年）。蘇我氏と物部氏の崇仏論争を経て、仏教は国家の宗教装置として受容されていく。 #ad/05/3/8 #歴史/宗教/仏教

645年 乙巳の変で蘇我入鹿が暗殺され、大化の改新が始まる。公地公民・班田収授など、唐の律令制をモデルにした中央集権化の第一歩。 {ev taik0645 #ad/06/4/5 #histolog/日本史 }

## 奈良時代

710年 平城京へ遷都 {ev nara0710 #ad/07/1/0 }

律令制と遣唐使の時代。奈良時代は 794 年まで続く。天平文化が花開き、東大寺・国分寺の造営（743年 大仏造立の詔 #ad/07/4/3 ）、『古事記』（712年 #ad/07/1/2 ）『日本書紀』（720年 #ad/07/2/0 ）『万葉集』の編纂と、この一段落だけでも複数の年代が折り重なる。

752年 東大寺大仏開眼供養。インド僧菩提僊那が導師を務め、シルクロード経由の文物が正倉院に納められた——同じ頃、唐は安史の乱（755年）前夜である。 #ad/07/5/2 #歴史/文化史

## 平安時代

794年 平安京へ遷都 {ev heia0794 #ad/07/9/4 }

894年 菅原道真の建議で遣唐使を停止。以後「国風文化」が育ち、仮名文字・物語文学（『源氏物語』は1008年ごろ #ad/10/0/8 ）が生まれる。 #ad/08/9/4 #歴史/文化史

1016年 藤原道長が摂政に。摂関政治の全盛期で、「この世をば わが世とぞ思ふ 望月の…」の歌はこの直後（1018年）に詠まれた。 #ad/10/1/6

1086年 白河上皇が院政を開始し、摂関政治は形骸化していく。 #ad/10/8/6

1156年 保元の乱、1159年 平治の乱。武士が中央政治の主役に躍り出る転換点。 #ad/11/5/6 #ad/11/5/9 #歴史/名詞と概念/武士の台頭

1185年 壇ノ浦の戦いで平家滅亡 {ev genp1185 #ad/11/8/5 }

## 中世

1192年 源頼朝が征夷大将軍に。鎌倉幕府の成立年は 1185 年説が有力になりつつある。 #ad/11/9/2

1274年・1281年 元寇（文永・弘安の役）。「神風」の記憶は後世のナショナリズムに長く影を落とす。 {ev genk1274 #ad/12/7/4 #histolog/日本史 #histolog/中国史 } #ad/12/8/1

1333年 鎌倉幕府滅亡、建武の新政へ。 #ad/13/3/3
1336年 足利尊氏が室町幕府を開き、南北朝の動乱が始まる（1392年合一 #ad/13/9/2 ）。 #ad/13/3/6

1467年 応仁の乱。京都は焼け野原となり、戦国時代の幕が開く。 {ev onin1467 #ad/14/6/7 #histolog/日本史 }

## 近世

1543年 種子島に鉄砲伝来。ポルトガル人を乗せた中国船の漂着だった——同年、コペルニクスの『天球の回転について』が出版されている。 #ad/15/4/3 #歴史/世界のなかの日本

1590年 豊臣秀吉の天下統一。 #ad/15/9/0

1603年 徳川家康が征夷大将軍に、江戸幕府成立。 {ev edob1603 #ad/16/0/3 #histolog/日本史 }
